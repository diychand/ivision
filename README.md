markdown# iVision — AI-Driven Model Training Platform

An end-to-end ML platform for training, evaluating, and deploying machine learning models without writing code.

## Features

- **Multi-Engine Training** — Scikit-learn (tabular), PyTorch CNN (images), PyTorch LSTM (NLP), YOLOv8 (object detection)
- **Data Labelling** — Text labelling with Active Learning, Image labelling with bounding boxes
- **Model Export** — ONNX and TFLite export for edge deployment
- **Model Versioning** — Track and manage model versions
- **YOLO Pipeline** — Label images → Export YOLO → Train YOLOv8 → Export ONNX → Deploy

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React (Vite), Axios |
| Backend | FastAPI, SQLAlchemy |
| Database | PostgreSQL (Docker) |
| ML | Scikit-learn, PyTorch, Ultralytics YOLOv8 |

## Setup

### Prerequisites
- Python 3.10+
- Node.js 18+
- Docker Desktop

### 1. Clone the repository
```bash
git clone https://github.com/diychand/ivision.git
cd ivision
```

### 2. Start the database
```bash
docker run --name ivision-db \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=password123 \
  -e POSTGRES_DB=ivision \
  -p 5432:5432 -d postgres
```

### 3. Setup backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Create a `.env` file inside `backend/`:
DATABASE_URL=postgresql://admin:password123@localhost:5432/ivision
ALLOWED_ORIGINS=http://localhost:5173
SECRET_KEY=your-secret-key-here

Start backend:
```bash
uvicorn main:app --reload
```

### 4. Setup frontend
```bash
cd frontend
npm install
npm run dev
```

### 5. Open the app
Visit `http://localhost:5173`

## Usage

### Train a CSV model
1. Upload a CSV file in Datasets
2. Go to Training → select dataset → Classification → Start Training
3. View results in Models page

### Train an image model
1. Upload a ZIP of images (folders = class names)
2. Training → Object Detection → Start Training

### Label and retrain
1. Image Labelling → draw bounding boxes → Export YOLO
2. Training → Object Detection → train on labelled data
3. Export → ONNX/TFLite for deployment
